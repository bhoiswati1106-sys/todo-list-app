# ✅ To-Do List App

A simple task manager to add and delete daily tasks, with tasks saved in the browser.

🔗 **Live Demo:** https://bhoiswati1106-sys.github.io/todo-list-app/


## ✨ Features

- Add new tasks
- Delete tasks
- Tasks stay saved after page refresh using Local Storage

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling)
- Local Storage

## 🚀 How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/bhoiswati1106-sys/[your-repo-name].git
   ```
2. Open the project folder
   ```bash
   cd [your-repo-name]
   ```
3. Open `index.html` in your browser. No installation is needed.
